# E2-Revision — fiches de révision

Site statique des fiches de révision du semestre 3 (HEIA-FR, Génie électrique, ING2).

**Site : <https://philippe-ong.github.io/E2-Revision/>**

Le contenu est **généré automatiquement** depuis l'arbre privé ING2 par
`Semestre-3/_commun/scripts/fiches-revision/publier_site_fiches.py`.
Ne pas modifier ce dépôt à la main : les changements seraient écrasés à la
prochaine publication.

- Seules les pages HTML **autonomes** sont publiées (aucun fichier annexe, aucune
  dépendance réseau) ; les PDF du cours et les énoncés ne le sont pas.
- Les liens vers les documents du cours sont remplacés par des étiquettes non
  cliquables.
- Les pages portent `<meta name="robots" content="noindex">` pour ne pas apparaître
  dans les moteurs de recherche.
