Les valeurs viennent des mesures du TP2 recalculées (Ra, Rf, Ui/n) ou d'un calcul explicite à partir d'elles ; en moteur la convention est celle du récepteur (u = R i + ui), en génératrice Ua = Ui − Ra Ia.

Exercices 1 2
01
constitution

La MCC à aimants permanents : un induit tournant dans un champ fixe

Le stator crée un champ magnétique constant, le rotor porte l'induit et tourne, le collecteur et les balais relient les conducteurs tournants au circuit extérieur. Le chapitre modélise cette machine ; le banc du TP est une variante à excitation bobinée séparée.

À retenir

Les aimants permanents remplacent l'enroulement d'excitation : le flux est fixé une fois pour toutes, donc kΦ est constant. Sur le banc du TP, l'excitation est bobinée séparée : If est réglable, Rf = 64 Ω mesurée à l'ohmmètre, et le flux peut varier (défluxage, section 12).

Note

Le cours de référence est intitulé « MCC à aimants permanents ». Les énoncés de laboratoire déposés décrivent en revanche une MCC à excitation bobinée séparée : c'est l'énoncé qui fait foi pour le banc, le vocabulaire du cours (Laplace, tension induite, Mem, τe, τm) reste la base d'analyse. La différence se voit au défluxage (section 12).

02
laboratoire

La force de Laplace et le collecteur produisent un couple

Un conducteur parcouru par un courant i et plongé dans un champ B subit la force F = i l × B. Sur le rotor, cette force crée un couple ; le collecteur inverse le courant au passage du pôle pour garder le couple dans le même sens.

Force de Laplace F = i · l × B |F| = i · l · B si i ⊥ B Couple d'un conducteur à la distance r de l'axe : M = F · r
La règle

Sens par la règle des trois doigts de la main gauche : index = champ B, majeur = courant i, pouce = force F. Le couple est maximal quand B et le courant sont perpendiculaires, nul quand ils sont parallèles.

Laboratoire · force et commutation
six états — exemple de calcul : B = 0,8 T, l = 0,2 m, r = 0,075 m
6 états
Le piège

Le collecteur ne crée pas le couple : il inverse le courant pour que le couple garde le même signe. Sans lui, le couple s'inverserait à chaque demi-tour et la machine ne tournerait pas de façon continue. Les valeurs de ce laboratoire sont un exemple de calcul, pas des mesures du banc.

03
couple

Le couple électromagnétique est proportionnel au courant d'induit

En sommant la force de Laplace sur tous les conducteurs de l'induit, le couple s'écrit Mem = kΦ i. Pour une MCC à aimants permanents, kΦ ne dépend que de la géométrie et du flux des aimants : il est constant.

Couple électromagnétique Mem = kΦ · i avec kΦ en N·m/A = V·s/rad Sur le banc à excitation nominale : kΦ ≈ 2,22 N·m/A
Couple calculé avec kΦ = 2,22 N·m/A
Courant d'induit i0 A5 A10 A15 A17,2 A
Couple Mem0 N·m11,1 N·m22,2 N·m33,3 N·m38,2 N·m
La règle

kΦ est la même constante dans les deux équations de conversion : Mem = kΦ i et ui = kΦ Ω. C'est le lien entre le monde électrique et le monde mécanique.

Note

Pour une MCC à excitation bobinée, kΦ dépend de If : le couple n'est plus proportionnel au seul courant d'induit. C'est le cas du banc au défluxage (section 12).

Le piège

Mem n'est pas le couple à l'arbre : les pertes fer et mécaniques se retranchent. Le banc n'a pas de couplemètre : le relevé note Mé-m = Pi/Ω, calculé à partir des grandeurs électriques, ce qui correspond au couple électromagnétique et non à un couple mesuré à l'arbre.

04
tension induite

La tension induite est proportionnelle à la vitesse

Les conducteurs coupent le flux : la fém induite vaut ui = kΦ Ω, avec la même kΦ que pour le couple. L'essai moteur du TP donne Ui/n = 0,2330 V/rpm, soit kΦ ≈ 2,22 V·s/rad.

05
modèle

L'équation électrique de l'induit

L'induit est un circuit R-L en série avec la fém ui. La tension u imposée se partage entre la chute ohmique, le terme inductif et la fém.

Équation électrique u = R · i + L · di/dt + ui avec ui = kΦ Ω En régime permanent (di/dt = 0) : u = R · i + kΦ Ω
La règle

En régime permanent, i = (u − ui)/R. C'est la forme à utiliser pour un point de fonctionnement ; la forme différentielle ne sert que pour les transitoires.

Note

L (inductance d'induit) n'est pas mesurée sur le banc : elle n'intervient que dans le transitoire, via τe = L/R (section 10). Aucune valeur numérique de L n'est affichée.

Le piège

Le terme L di/dt n'est pas une chute ohmique : il ne dissipe pas de puissance, il stocke de l'énergie magnétique. Ne pas l'ajouter à R i pour calculer des pertes.

06
modèle

L'équation mécanique de l'arbre

Le rotor a une inertie J. Le couple électromagnétique l'accélère ; le couple résistant de la charge et le frottement visqueux s'y opposent.

Équation mécanique J · dΩ/dt = Mem − Mr − f · Ω En régime permanent : Mem = Mr + f · Ω
La règle

Le couple électromagnétique ne sert pas seulement à entraîner la charge : il doit aussi couvrir le frottement. À vitesse constante, Mem égale exactement la somme des couples résistants.

Note

J et f ne sont pas mesurés sur le banc : l'équation donne la structure du modèle, pas les valeurs. Sur le relevé, le courant à vide du moteur (Ia = 1,34 A à 400 V) traduit le couple de frottement.

Le piège

Mr est le couple de la charge ; il ne dépend pas de la vitesse du moteur. Le frottement f Ω, lui, augmente avec Ω : les deux termes ne se confondent pas.

07
schéma-bloc

Le modèle dynamique couple les deux équations

Les deux équations forment un système : la tension u et le couple résistant Mr sont les entrées, le courant i et la vitesse Ω les sorties. La fém ui = kΦ Ω est la contre-réaction qui relie les deux mondes.

Système d'équations u = R · i + L · di/dt + kΦ · Ω J · dΩ/dt = kΦ · i − Mr − f · Ω Entrées : u, Mr Sorties : i, Ω
La règle

Avec kΦ constant, le système est linéaire : deux équations du premier ordre couplées, caractérisées par τe et τm (section 10). Pour une entrée u, la vitesse Ω se comporte comme un système du deuxième ordre.

Note

Le modèle réel comporte des non-linéarités : saturation du circuit magnétique (qui fait varier kΦ), frottement non visqueux, jeu mécanique, commutation. Le modèle linéaire reste le cadre d'analyse et de dimensionnement.

08
régime permanent

Le régime permanent fixe le point de fonctionnement

Quand les transitoires sont terminés, les deux équations donnent i = (u − kΦ Ω)/R et Ω = (u − R i)/(kΦ). Le point de fonctionnement est l'intersection de la caractéristique du moteur et de celle de la charge.

Régime permanent i = (u − kΦ · Ω) / R Ω = u / (kΦ) − R · Mr / (kΦ)² Vitesse à vide (couple résistant nul) : n0 = 60 · u / (2π · kΦ)
Laboratoire · point de fonctionnement à u constant
six états — Ra = 1,474 Ω, kΦ = 2,22 V·s/rad, u = 400 V
6 états
À retenir

À tension d'induit constante, la vitesse ne dépend du couple que par la chute R i. La caractéristique est dite « dure » : 6,5 % de vitesse pour 38,9 N·m, ce qui explique l'usage de la MCC en entraînement à vitesse stable.

Le piège

Croire que la vitesse baisse fortement quand la charge augmente, ou croire qu'elle est totalement indépendante du couple : les deux sont faux. Le bon raisonnement passe par i puis par la chute R i.

À u = 400 V et Mr = 10 N·m, calculer i puis n.
i = Mr/kΦ = 10/2,22 = 4,50 A ; ui = 400 − 1,474 × 4,50 = 393,4 V ; n = 60 × 393,4/(2π × 2,22) ≈ 1 692 tr/min.
09
démarrage

Le démarrage impose une limitation du courant

À l'enclenchement, Ω = 0 donc ui = 0 : toute la tension tombe dans la résistance, i = u/R. Avec u = 400 V et Ra = 1,474 Ω, i ≈ 271 A. L'inductance ne limite que le tout premier instant.

Courant de démarrage À Ω = 0 : idémarrage = u / R = 400 / 1,474 = 271 A Avec un rhéostat série Rd : i = u / (R + Rd)
Laboratoire · établissement de la vitesse
six états — u = 400 V, couple résistant négligé, L négligée
6 états
La règle

On démarre sous tension réduite (variateur) ou avec un rhéostat en série. Abaisser la tension à 100 V donne i = 67,9 A, quatre fois moins qu'à 400 V. Le rhéostat, lui, dissipe de la puissance : il ne sert qu'au démarrage.

Le piège

L ne limite pas le courant de démarrage durable : la constante τe = L/R est très courte, et c'est R qui fixe le courant après le transitoire. Le courant d'appel reste donc u/R tant que la vitesse est nulle.

10
dynamique

Les constantes de temps séparent les échelles

Le modèle linéaire a deux constantes : τe = L/R pour le courant, τm = JR/(kΦ)² pour la vitesse. Ni L ni J ne sont mesurés sur le banc : on donne la structure, pas les valeurs.

Constantes de temps τe = L / R τm = J · R / (kΦ)² Ordre de grandeur : τm ≫ τe (le courant s'établit avant que la vitesse ne change)
La règle

τm ≫ τe est la raison pour laquelle on peut régler le courant (donc le couple) indépendamment de la vitesse, en cascade : la boucle de courant est beaucoup plus rapide que la boucle de vitesse.

Note

τm est proportionnel à J et à 1/(kΦ)² : un rotor plus inerte ou moins fortement aimanté est plus lent. Sur le banc, aucune valeur de L ou de J n'est disponible.

Le piège

Ne pas confondre les deux échelles : τe concerne le courant et le circuit électrique, τm concerne la vitesse et l'inertie. Écrire une valeur chiffrée sans L ni J serait une invention.

11
énergie

Le bilan des puissances donne le rendement

La puissance électrique absorbée vaut Pél = u i ; la puissance convertie vaut Pméc = Mem Ω = ui i. L'écart est la perte cuivre R i². En génératrice, le sens s'inverse.

12
commande

Le réglage de la vitesse agit sur la tension et sur le flux

Comme Ω ≈ u/(kΦ), on règle la vitesse par la tension d'induit. Pour une MCC à aimants permanents, kΦ est fixé par les aimants ; sur une machine à excitation bobinée, on peut aussi réduire If : c'est le défluxage.

Réglage de la vitesse Ω = u / (kΦ) → n = 60 · u / (2π · kΦ) Défluxage (excitation bobinée) : n ∝ 1 / Φ si Φ ∝ If

La règle

Défluxer augmente la vitesse à tension donnée, mais diminue le couple disponible à courant égal (M = kΦ i). Pour une MCC à aimants permanents, ce réglage n'existe pas : la vitesse se règle par la tension d'induit.

Note

Sur le banc, Ui n'est pas resté constant : 46,8 → 43,4 V, soit −7,4 %. Le relevé s'écarte donc de l'hypothèse de l'énoncé (Ui maintenu) : les points mesurés et la loi théorique ne se superposent pas.

Le piège

n ∝ 1/If n'est vrai que si Φ ∝ If, donc loin de la saturation et sans rémanence. Ce n'est pas le cas ici. Et ne pas appliquer le défluxage à une MCC à aimants permanents : le flux y est fixé.

Formules

  • Mem = kΦ i ; ui = kΦ Ω ; Ω = 2πn/60.
  • u = R i + L di/dt + ui ; J dΩ/dt = Mem − Mr − f Ω.
  • Régime permanent : i = (u − kΦ Ω)/R, n0 = 60u/(2π kΦ).
  • Pél = u i, Pméc = Mem Ω = ui i, Pcu = R i², η = Pméc/Pél.
  • τe = L/R ; τm = JR/(kΦ)².
  • Signes : moteur Ui = Ua − Ra Ia ; génératrice Ui = Ua + Ra Ia.

Checklist

  • Repérer le sens de fonctionnement avant d'écrire un signe.
  • Vérifier kΦ : constant (aimants) ou dépendant de If (bobiné).
  • À l'arrêt, ui = 0 : le courant vaut u/R.
  • En génératrice, retrancher Ra Ia de Ui pour obtenir Ua.
  • Contrôler les unités : kΦ en N·m/A = V·s/rad.
  • Distinguer Mem (converti) et couple à l'arbre (non mesuré).
  • Rendement : ne compter que les pertes connues.
