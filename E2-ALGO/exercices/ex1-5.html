Tri à bulles et compte des permutations

Trier dix nombres avec l'algorithme repeat … until s = 0 et compter les permutations.

exercice 1.5 tri à bulles · comparaisons · permutations · inversions · coût théorie : Algorithmes de tri
01
énoncé

Ce que demande l’exercice

a) Déclarer globalement un tableau de dix nombres choisis non triés et afficher tout son contenu avec printf.

b) Implémenter l'algorithme de l'énoncé : répéter, remettre s à 0, parcourir de 2 à N, échanger si A[i] est plus petit que A[i−1] et incrémenter s, jusqu'à ce que s vaille 0 ; puis afficher la table triée.

c) Afficher le nombre de permutations et faire des essais avec d'autres nombres et d'autres ordres.

La série de l'énoncé est 28, 3, 45, 1, 5, 17, 33, 32, 42 et 2 ; sa sortie annonce 20 permutations.

02
théorie nécessaire

Les notions à mobiliser

La bulle

Chaque passe compare les voisins de gauche à droite et échange les paires inversées : le plus grand élément atteint la dernière case. Après k passes, les k dernières cases sont définitives.

Le compteur s

s compte les échanges de la passe en cours et repart à 0 au début de chaque passe. Quand une passe entière n'échange rien, s vaut 0 et la boucle repeat s'arrête : le tableau est trié.

Permutations et inversions

Une inversion est une paire d'indices i plus petit que j avec t[i] supérieur à t[j]. Chaque échange de voisins en corrige exactement une : le nombre d'échanges égale le nombre d'inversions, quelle que soit la série.

Le coût

Une passe coûte 4N − 2 pas, un échange 5 (trois écritures et s := s + 1), le test d'arrêt 1 : c = P(4N − 2) + 5I, avec P passes et I permutations. Pour N = 10, une passe vaut 38 pas.

03
méthode

Comment procéder

  1. Déclarer le tableau en global et calculer sa taille par sizeof.
  2. Écrire le do … while : remise de s à 0, puis parcours de l'indice 1 à n−1.
  3. Échanger deux voisins avec une variable temporaire, puis incrémenter s.
  4. Cumuler les permutations dans un compteur distinct de s.
  5. Afficher le tableau de départ, le tableau trié et le total des permutations.
  6. Rejouer avec une série triée, puis avec l'ordre inverse, pour voir varier passes et échanges.
04
application

Application à l’énoncé

exemple.cC11
/* Tri à bulles du cours : repeat ... until s = 0.
   Rend le nombre total de permutations. */
uint32_t triABulles(int16_t t[], size_t n)
{
    uint32_t permutations = 0u;
    uint32_t s;
    do {
        s = 0u;                     /* le compteur repart à zéro */
        for (size_t i = 1u; i < n; i++) {
            if (t[i] < t[i - 1u]) { /* paire de voisins inversée */
                int16_t tmp = t[i];
                t[i] = t[i - 1u];
                t[i - 1u] = tmp;
                s++;
            }
        }
        permutations += s;
    } while (s != 0u);              /* until s = 0 : on s'arrête */
    return permutations;
}

05
erreurs fréquentes

Les pièges

À vérifier
  • Ne pas remettre s à 0 au début de chaque passe : la condition reste vraie et la boucle ne s'arrête jamais.
  • Boucler de 0 à n−1 : l'indice i−1 sort du tableau ; le parcours commence à 1.
  • Confondre permutations et comparaisons : 20 échanges mais 81 comparaisons sur la série de l'énoncé.
  • Prendre 45 pour le résultat de l'énoncé : 45 = 10 × 9 / 2 est le maximum, atteint par l'ordre inverse.
