Affichage d'un fichier

Afficher un fichier texte ligne par ligne, avec numérotation optionnelle par l'argument -l.

exercice 2.6 fgets · argv · option -l · numéros de ligne · fin de fichier théorie : Entrées/sorties et fichiers
01
énoncé

Ce que demande l’exercice

L'application affiche le contenu d'un fichier texte sur la console ; le nom du fichier et l'option -l sont passés en arguments.

L'étape a ouvre et ferme un fichier fixe dans main, avec la gestion d'erreur.

Le fichier est ensuite lu ligne par ligne avec fgets et réaffiché ; le nom passe en argument, puis -l ajoute le numéro de ligne.

Le même fichier, avec ou sans -l
Les trois lignes du fichier sont recopiées telles quelles, ou précédées de leur numéro sur quatre colonnes avec -l.
02
théorie nécessaire

Les notions à mobiliser

fopen et son mode

fopen("notes.txt", "r") renvoie NULL si le fichier manque. Le mode "w" tronque à zéro octet dès l'ouverture : un test en "w" détruit le contenu. Pour lire, "r" seul.

fgets garde le retour à la ligne

fgets(ligne, n, f) lit au plus n−1 caractères et garde le '\n' ; il renvoie ligne ou NULL. printf("%s") et fputs n'ajoutent pas de saut de ligne : la sortie reste exacte, même sans '\n' final.

Tester le retour, pas feof

feof ne devient vrai qu'après une lecture échouée. while (!feof(f)) { fgets(...); printf(...); } affiche la dernière ligne deux fois. La boucle correcte teste while (fgets(...) != NULL) ; ferror distingue l'erreur de la fin.

Numéroter avec -l

argc vaut 3 quand -l est présent. strcmp(argv[2], "-l") == 0 active la numérotation et argv[2] ne se lit que si argc == 3. no s'incrémente après chaque fgets réussi ; printf("%4lu %s") aligne sur quatre colonnes.

03
méthode

Comment procéder

  1. Vérifier argc (2 ou 3), sinon usage et retour 1.
  2. Calculer numeroter avec argc == 3 && strcmp(argv[2], "-l") == 0.
  3. Ouvrir argv[1] en "r" ; si NULL, perror et retour 1 sans fclose.
  4. Boucler avec fgets sur char ligne[256] et s'arrêter sur NULL.
  5. Incrémenter no, afficher avec %4lu ou fputs, puis tester ferror et fclose.
04
application

Application à l’énoncé

exemple.cC11
#include <stdio.h>
#include <string.h>

int main(int argc, char *argv[])
{
    if (argc < 2 || argc > 3) {
        printf("Usage : %s <fichier> [-l]\n", argv[0]);
        return 1;
    }
    int numeroter = (argc == 3 && strcmp(argv[2], "-l") == 0);

    FILE *f = fopen(argv[1], "r");
    if (f == NULL) {
        perror(argv[1]);
        return 1;
    }

    char ligne[256];
    unsigned long no = 0;
    while (fgets(ligne, sizeof ligne, f) != NULL) {
        no++;
        if (numeroter) {
            printf("%4lu  %s", no, ligne);   /* le '\n' vient de ligne */
        } else {
            fputs(ligne, stdout);
        }
    }
    if (ferror(f)) {
        perror("lecture");
        fclose(f);
        return 1;
    }
    fclose(f);
    return 0;
}

Avec un fichier de trois lignes dont la dernière n'a pas de retour à la ligne, la sortie observée est :

appelsortie
ex2-6 notes.txtpremiere ligne / deuxieme ligne / troisieme sans fin
ex2-6 notes.txt -l 1 premiere ligne / 2 deuxieme ligne / 3 troisieme sans fin

Une ligne de 300 caractères est lue en 255 puis 45 : elle compte pour deux numéros et décale la suite.

Résultat. Sans option, le fichier est recopié tel quel ; avec -l, chaque ligne reçoit son numéro sur quatre colonnes.
05
erreurs fréquentes

Les pièges

À vérifier
  • Piloter la boucle avec while (!feof(f)) : la dernière ligne est affichée deux fois.
  • Lire argv[2] sans vérifier argc == 3 : le pointeur n'existe pas.
  • Oublier fclose, ou l'appeler sur NULL après un fopen échoué : descripteur fuité.
  • Croire qu'un tampon de 256 octets lit des lignes de longueur quelconque : une ligne longue décale la numérotation.
