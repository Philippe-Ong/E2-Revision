FIFO sur liste chaînée

Implémenter une file FIFO sur liste chaînée : ajout en queue, retrait en tête, tests des cas limites.

exercice 3.1 createFIFO · put · get · Data_t** · pointeur de queue · cas limites théorie : Files FIFO
01
énoncé

Ce que demande l’exercice

Data_t contient sensorNumber (unsigned int), sensorValue (double), time (unsigned long) et pNext (Data_t*).

Trois fonctions sont imposées : createFIFO retourne la tête, put(Data_t**, Data_t) ajoute, get(Data_t**, Data_t*) retire et copie la valeur.

put et get reçoivent l'adresse du pointeur de tête, car ils peuvent le changer ; le booléen signale un échec.

L'énoncé demande aussi showList et un programme qui teste les exceptions, par exemple get sur une liste vide.

Tête, queue, get et put
get retire A en tête, put ajoute en queue derrière C ; la file se parcourt de la tête vers la queue.
02
théorie nécessaire

Les notions à mobiliser

Deux bouts, deux coûts

put ajoute en queue, get retire en tête : premier entré, premier sorti. Une file vide vaut NULL. Avec la seule tête, put est O(n) et get O(1) ; un pointeur de queue pTail rend put O(1), mais get doit le remettre à NULL quand la file se vide.

Data_t** : changer la tête de l'appelant

Un argument est copié : pour changer pList de main, put et get reçoivent &pList, de type Data_t**. *ppList est la tête, (*ppList)->pNext le deuxième nœud.

put : allouer, remplir, accrocher

malloc, puis *pNew = newElement et pNew->pNext = NULL. File vide : *ppList = pNew ; sinon on parcourt jusqu'au dernier et on écrit pFlow->pNext = pNew. malloc en échec : false, liste intacte.

get : détacher, copier, libérer

Tester *ppList == NULL. Sauver pOld, avancer la tête *ppList = pOld->pNext, recopier les champs, mettre pElement->pNext = NULL, puis free(pOld).

03
méthode

Comment procéder

  1. Définir Data_t avec ses quatre champs ; createFIFO retourne NULL.
  2. put : allouer, recopier, pNext = NULL, accrocher en queue.
  3. get : tester la file vide, avancer la tête, recopier, libérer.
  4. showList : parcourir sans modifier la tête.
  5. Tester 5 put, 5 get, get sur vide, put après vidage.
04
application

Application à l’énoncé

exemple.cC11
#include <stdio.h>
#include <stdlib.h>
#include <stdbool.h>

typedef struct Data_s {
    unsigned int  sensorNumber;
    double        sensorValue;
    unsigned long time;
    struct Data_s *pNext;
} Data_t;

Data_t* createFIFO(void)
{
    return NULL;             /* file vide */
}

bool put(Data_t** ppList, Data_t newElement)
{
    if (ppList == NULL) { return false; }

    Data_t* pNew = (Data_t*)malloc(sizeof(Data_t));
    if (pNew == NULL) { return false; }  /* file intacte */

    *pNew = newElement;
    pNew->pNext = NULL;      /* nouveau dernier */

    if (*ppList == NULL) {
        *ppList = pNew;      /* file vide : tete = queue */
    } else {
        Data_t* pFlow = *ppList;
        while (pFlow->pNext != NULL) {
            pFlow = pFlow->pNext;
        }
        pFlow->pNext = pNew; /* accroche en queue */
    }
    return true;
}

bool get(Data_t** ppList, Data_t* pElement)
{
    if (ppList == NULL || pElement == NULL
        || *ppList == NULL) {
        return false;        /* file vide */
    }

    Data_t* pOld = *ppList;
    *ppList = pOld->pNext;   /* la tete avance */

    pElement->sensorNumber = pOld->sensorNumber;
    pElement->sensorValue  = pOld->sensorValue;
    pElement->time         = pOld->time;
    pElement->pNext        = NULL; /* pas pOld->pNext */

    free(pOld);
    return true;
}

int main(void)
{
    Data_t* pList = createFIFO();
    for (unsigned int i = 0; i < 5; i++) {
        Data_t e = { i, 0.1 * i * i, 100UL + i, NULL };
        if (!put(&pList, e)) {
            printf("No more memory\n");
            return 1;
        }
    }

    Data_t out;
    while (get(&pList, &out)) {
        printf("sensor=%u value=%f time=%lu\n",
               out.sensorNumber, out.sensorValue, out.time);
    }

    printf("get sur vide : %s\n",
           get(&pList, &out) ? "true" : "false");
    return 0;
}

Cinq éléments 0 à 4 insérés puis retirés sortent dans l'ordre 0, 1, 2, 3, 4.

opérationétat de la fileretour

put(&pList, e0)e0true
put(&pList, e4)e0 e1 e2 e3 e4true
get(&pList, &out) × 50, 1, 2, 3, 4 puis videtrue

Après cinq get, la tête vaut NULL et un sixième retourne false. Pour put en O(1), on mémorise pTail : pTail->pNext = pNew puis pTail = pNew.

Résultat. Ordre FIFO conservé : 0 sort le premier ; après cinq get, get retourne false.
05
erreurs fréquentes

Les pièges

À vérifier
  • Accrocher en tête au lieu de la queue : la liste devient un LIFO.
  • Recopier le pNext du nœud sorti : pointeur vers un bloc libéré.
  • Oublier free(pOld) dans get : fuite mémoire à chaque retrait.
  • Ne pas tester malloc : écrire dans le nœud si pNew vaut NULL.
