Structure de gestion du temps

Afficher la date et l'heure avec un struct tm, situer l'overflow d'un time_t de 32 bits et centraliser l'affichage dans deux fonctions.

exercice 1.7 struct tm · time_t · pointeurs · Y2038 théorie : Structures
01
énoncé

Ce que demande l’exercice

L'application utilise la structure tm de time.h : neuf champs int pour les secondes, minutes, heures, jour du mois, mois, année, jour de semaine, jour de l'année et heure d'été.

a) Afficher dans main() la date et l'heure actuelles avec printf, au format jj.mm.aaaa hh:mm:ss.

b) Afficher l'instant exact où un time_t de 32 bits signé déborde, avec les constantes de limits.h.

c) Regrouper l'affichage dans une fonction qui reçoit le texte et la structure.

d) Écrire une fonction qui traduit le numéro du jour en nom et l'appeler dans printf.

Mémoire de struct tm
Neuf int de 4 octets, contigus : offsets 0 à 32 et 36 octets au total, sans bourrage.
02
théorie nécessaire

Les notions à mobiliser

Neuf int, deux décalages

tm_mon part de 0 (octobre vaut 9), d'où tm_mon + 1. tm_year compte depuis 1900 (2026 vaut 126), d'où tm_year + 1900. Les neuf int sont contigus : sizeof(struct tm) vaut 36 octets.

localtime rend un pointeur

time(NULL) rend un time_t : les secondes depuis 1970. localtime(&t) le décompose et rend un struct tm * : *localtime(&t) copie la structure, localtime(&t)->tm_hour lit un champ.

L'overflow de 2038

Un time_t de 32 bits signé plafonne à INT_MAX = 231 − 1 = 2 147 483 647 s ; une seconde plus tard il devient négatif (Y2038). localtime(INT_MAX) donne 19.01.2038 03:14:07 UTC, 04:14:07 en Suisse, un mardi.

Un format, une fonction

DATE_FORMAT vaut "%02d.%02d.%04d %02d:%02d:%02d" ; on écrit "%s" DATE_FORMAT pour préfixer, jamais un char * dans un %d. showTime copie la structure (36 octets). Les noms viennent d'un static const, valide après le return.

03
méthode

Comment procéder

  1. Lire time(NULL) dans un time_t, puis décomposer avec *localtime(&now).
  2. Afficher tm_mday, tm_mon + 1, tm_year + 1900, tm_hour, tm_min et tm_sec.
  3. Décomposer (time_t)INT_MAX de la même façon pour l'overflow.
  4. Déplacer les deux affichages dans showTime(texte, structure).
  5. Traduire tm_wday avec weekDayName et un tableau static const de sept noms.
04
application

Application à l’énoncé

exemple.cC11
#include <limits.h>
#include <stdio.h>
#include <time.h>

#define DATE_FORMAT "%02d.%02d.%04d %02d:%02d:%02d"

/* c) texte + struct tm passée par valeur (copie) */
void showTime(char const *text, struct tm t)
{
    printf("%s" DATE_FORMAT "\n", text, t.tm_mday, t.tm_mon + 1,
           t.tm_year + 1900, t.tm_hour, t.tm_min, t.tm_sec);
}

/* d) tm_wday (0 = dimanche) -> nom du jour */
char const *weekDayName(int weekDay)
{
    static char const *const cNames[] = {"Sunday",
        "Monday", "Tuesday", "Wednesday", "Thursday",
        "Friday", "Saturday"};
    if (weekDay < 0 || weekDay > 6) {
        return "?";                          /* hors table */
    }
    return cNames[weekDay];
}

/* b) dernière seconde d'un time_t 32 bits signé */
struct tm lastSecondOfTime32(void)
{
    time_t const cMax = (time_t)INT_MAX;
    return *localtime(&cMax);   /* localtime rend un POINTEUR */
}

Le 15.10.2026, tm_year vaut 126 et tm_mon vaut 9 : l'affichage ajoute 1900 et 1 ; tm_wday vaut 4, un jeudi.

Pour l'overflow, (time_t)INT_MAX vaut 2 147 483 647 s, soit 19.01.2038 03:14:07 UTC et 04:14:07 à Fribourg : un mardi.

Résultat. a) 15.10.2020 09:21:25 ; b) overflow 1 s après 19.01.2038 04:14:07 ; d) « Thursday » pour tm_wday = 4.

erreurs fréquentes

Les pièges

À vérifier
  • Oublier tm_mon + 1 et tm_year + 1900 : mois précédent et année 126.
  • Passer un char * à %02d : DATE_FORMAT commence par %02d, d'où "%s" DATE_FORMAT.
  • Déréférencer localtime sans étoile : il rend un struct tm *, pas une structure.
