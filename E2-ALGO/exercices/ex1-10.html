Tours de Hanoï

Déplacer n disques de A vers B selon les règles, puis compter les coups sans variable globale.

exercice 1.10 récursivité · 2^n − 1 · pile d'appels · compteur théorie : Récursivité
01
énoncé

Ce que demande l’exercice

L'algorithme « Tower of Hanoi » déplace n disques de l'aiguille A vers B, avec C comme auxiliaire : un disque à la fois, jamais un grand sur un petit.

a) Implémenter la fonction de façon récursive et la tester avec plusieurs valeurs de n.

b) Afficher le nombre de mouvements après l'appel de toh, sans variable globale.

Pseudo-code de l'énoncé : si disk vaut 1, déplacer le disque ; sinon toh(disk − 1, source, aux, dest), déplacer, puis toh(disk − 1, aux, dest, source).

Pour n = 3, la sortie affiche 7 déplacements : « For n=3, 7 moves were necessary ».

Trois aiguilles, un déplacement
Avant et après le coup 1 : le disque 1 quitte A pour B, les disques 2 et 3 restent empilés sur A.
02
théorie nécessaire

Les notions à mobiliser

Cas simple et réduction

Le cas de base est disk == 1 : un déplacement, aucune récursion. Pour n > 1, on déplace n − 1 disques sur l'auxiliaire, le plus grand sur la destination, puis les n − 1 par-dessus.

M(n) = 2 M(n−1) + 1 = 2^n − 1

Chaque niveau double le travail précédent : 1, 3, 7, 15, 31 coups. Complexité O(2^n) en temps, O(n) en pile, la profondeur valant n.

L'ordre des paramètres

toh(disk, source, dest, aux) : le premier appel échange dest et aux, puisque les n − 1 disques visent l'auxiliaire ; le second échange source et aux. Un mauvais paramètre produit des déplacements illégaux.

Un compteur, pas une globale

moveDisk reçoit uint32_t *pMoves et fait (*pMoves)++ : la fonction reste réentrante et l'appelant choisit où vit le compteur.

03
méthode

Comment procéder

  1. Écrire le cas simple : disk == 1, un seul moveDisk de source vers dest.
  2. Sinon, déplacer disk − 1 disques de source vers aux, avec dest comme auxiliaire.
  3. Déplacer le disque disk de source vers dest.
  4. Déplacer les disk − 1 disques de aux vers dest, avec source comme auxiliaire.
  5. Compter dans (*pMoves)++ et vérifier n = 3 → 7, n = 10 → 1 023.
04
application

Application à l’énoncé

exemple.cC11
#include <stdint.h>
#include <stdio.h>

static void moveDisk(uint32_t disk, char from, char to,
                     uint32_t *pMoves)
{
    printf("Move disk %u from %c to %c\n",
           (unsigned)disk, from, to);
    (*pMoves)++;        /* b) compteur sans variable globale */
}

/* Ex. 1.10 : pseudo-code de l'énoncé ; *pMoves compte */
void toh(uint32_t disk, char source, char dest, char aux,
         uint32_t *pMoves)
{
    if (disk == 1u) {                          /* cas simple */
        moveDisk(1u, source, dest, pMoves);
    } else {
        toh(disk - 1u, source, aux, dest, pMoves); /* -> aux */
        moveDisk(disk, source, dest, pMoves);    /* le grand */
        toh(disk - 1u, aux, dest, source, pMoves); /* -> dest */
    }
}

Les coups 1 à 3 déplacent deux disques de A vers C, le coup 4 place le disque 3 sur B, les coups 5 à 7 répètent de C vers B.

2^3 − 1 = 7, 2^10 − 1 = 1 023, 2^64 − 1 = 18 446 744 073 709 551 615.

Résultat. n = 3 : 7 coups et 3 niveaux d'appels ; n = 10 : 1 023 coups ; n = 64 : 18 446 744 073 709 551 615 coups, soit environ 585 ans à 10^9 coups par seconde.
05
erreurs fréquentes

Les pièges

À vérifier
  • Inverser dest et aux dans le premier appel : les disques visent la mauvaise aiguille.
  • Compter avec une globale rend la fonction non réentrante ; passer uint32_t *pMoves.
  • Croire le coût linéaire : 2^n − 1, soit 585 ans à 10^9 coups/s pour 64 disques.
