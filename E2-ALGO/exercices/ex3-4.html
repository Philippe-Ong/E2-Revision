Lotto : huit tirages sur liste doublement chaînée

Générer huit tirages de six numéros distincts dans une liste doublement chaînée triée, en suivant les opérations numérotées 1) à 7) du corrigé officiel.

exercice 3.4 liste doublement chaînée · pNext/pPrev · put · doublons · rand/srand théorie : Listes chaînées
01
énoncé

Ce que demande l’exercice

Le programme simule huit tirages SwissLotto. Chaque tirage contient six numéros distincts choisis entre 1 et 42, plus un numéro chance entre 1 et 6.

La liste est doublement chaînée : chaque Element_t contient number (LottoNbr_t = unsigned char), pNext et pPrev. Elle reste triée par ordre croissant.

a) implémenter showList ; b) dessiner l'insertion de 3 dans une liste contenant déjà 2 et 8 ; c) traiter les cas 1 (nouvelle tête) et 42 (nouvelle queue) ; d) implémenter put.

Le programme initialise srand(time(0)) une seule fois, génère les six numéros avec generateNumbers, affiche la liste et le numéro chance, puis appelle clearList.

Le corrigé officiel (6 pages) donne showList, les schémas b) et c) avec les opérations 1) à 7), et put qui reprend cette numérotation.

Schéma b) du corrigé : les liens 2 → 8 et 8 → 2 (pointillés) sont remplacés par quatre liens numérotés dans l'ordre du code de put.
02
théorie nécessaire

Les notions à mobiliser

Nœud double

Chaque Element_t contient number, pNext et pPrev. La tête a pPrev == NULL, la queue pNext == NULL. showList parcourt avec pFlow et affiche %2d, ou « List is empty... ».

Trouver la place

Le corrigé alloue et initialise (pNext = pPrev = NULL), traite la liste vide (*ppList = pElem), puis avance pFlow tant que pElem->number > pFlow->number et pFlow->pNext != NULL. pFlow s'arrête sur le premier plus grand, ou sur le dernier nœud.

Avant pFlow : 1) à 4), et 7) en tête

Si pElem->number < pFlow->number : en tête (pFlow->pPrev == NULL), 7) *ppList = pElem ; sinon 1) pFlow->pPrev->pNext = pElem, 2) pElem->pPrev = pFlow->pPrev. Puis toujours 3) pFlow->pPrev = pElem, 4) pElem->pNext = pFlow.

Après le dernier : 5) et 6)

Sinon le nombre dépasse le dernier : 5) pElem->pPrev = pFlow, 6) pFlow->pNext = pElem. Les doublons sont exclus en amont par isAlreadyTaken dans generateNumbers ; srand(time(0)) est appelé une seule fois.

03
méthode

Comment procéder

  1. showList : parcourir avec pFlow et afficher chaque numéro en %2d ; « List is empty... » si la liste est vide.
  2. put a)–d) : allouer, tester malloc, initialiser pNext et pPrev à NULL ; liste vide → *ppList = pElem.
  3. put e)–g) : avancer pFlow tant que le nombre est plus grand et qu'il reste un suivant.
  4. Plus petit que pFlow : 1) et 2) (ou 7) en tête), puis 3) et 4) ; sinon après le dernier : 5) et 6).
  5. main : 8 tirages de 6 numéros (rand() % 42 + 1, sans doublon), numéro chance rand() % 6 + 1, puis clearList.
04
application

Application à l’énoncé

exemple.cC11
typedef unsigned char LottoNbr_t;

typedef struct Element_s {
    LottoNbr_t        number;
    struct Element_s* pNext;
    struct Element_s* pPrev;
} Element_t;

/// a) Shows the stored elements of the sorted list
void showList(Element_t* pList)
{
    Element_t* pFlow = pList;
    if (NULL == pFlow) {
        printf("List is empty...");
    } else {
        while (NULL != pFlow) {
            printf("%2d ", pFlow->number);
            pFlow = pFlow->pNext;
        }
    }
}

/// d) Add a new element to the sorted list (lower numbers first)
bool put(Element_t** ppList, LottoNbr_t nbr)
{
    // a) allocate memory
    Element_t* pElem = (Element_t*) malloc(sizeof(Element_t));
    if (NULL == pElem) {
        return false;
    }
    // b) initialize element
    pElem->number = nbr;
    pElem->pNext  = NULL;
    pElem->pPrev  = NULL;

    // c) Check if list is empty?
    if (NULL == *ppList) {
        *ppList = pElem;                  // d) Adjust list pointer
        return true;
    } else {
        Element_t* pFlow = *ppList;       // e) get first element
        // f) Check where to insert
        while ((pElem->number > pFlow->number) && (NULL != pFlow->pNext)) {
            pFlow = pFlow->pNext;         // g) point to next element
        }
        if (pElem->number < pFlow->number) {
            // before pFlow
            if (NULL == pFlow->pPrev) {
                *ppList = pElem;              // 7) new head
            } else {
                pFlow->pPrev->pNext = pElem;  // 1)
                pElem->pPrev = pFlow->pPrev;  // 2)
            }
            pFlow->pPrev = pElem;             // 3)
            pElem->pNext = pFlow;             // 4)
        } else {
            // after last element
            pElem->pPrev = pFlow;             // 5)
            pFlow->pNext = pElem;             // 6)
        }
        return true;
    }
}

static void generateNumbers(Element_t** ppList, unsigned int nbrOfNumbers)
{
    for (unsigned int i = 0; i < nbrOfNumbers; i++) {
        LottoNbr_t newNumber = 0;
        do {
            newNumber = (rand() % eTotalNbrOfLottoNumbers) + 1;
        } while (isAlreadyTaken(*ppList, newNumber));
        put(ppList, newNumber);
    }
}

Résultat. Huit lignes de six numéros triés et distincts, suivies du numéro chance ; la liste doublement chaînée est vidée après chaque tirage.
05
erreurs fréquentes

Les pièges

À vérifier
  • Faire 3) avant 1) et 2) : pFlow->pPrev pointe déjà sur le nouveau nœud, qui se relie à lui-même et 2 reste relié à 8.
  • Oublier 7) : un plus petit numéro est relié devant la tête, mais *ppList pointe toujours sur l'ancienne.
  • Supprimer isAlreadyTaken : le put du corrigé place un doublon « après » pFlow et coupe la liste (2, 8 puis 2 → 2 ⇄ 2, le 8 est perdu).
  • Appeler srand dans la boucle des tirages, ou oublier clearList : suite répétitive ou fuite mémoire.
