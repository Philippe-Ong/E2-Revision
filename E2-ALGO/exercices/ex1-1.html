02
théorie nécessaire

Les notions à mobiliser

Types et promotions

Le type fixe la taille et la lecture des bits : unsigned char 8 bits, short 16 bits, int 32 bits, float 32 bits, double 64 bits. char et short sont promus en int dans une expression ; dès qu'un double participe, tout se calcule en double, et une affectation reconvertit vers le type de la variable.

Priorités et associativité

*, / et % passent avant + et - ; les comparaisons passent avant &, ^ et | ; l'affectation vient en dernier. D'où x & m == 0, qui vaut x & (m == 0).

Booléens et points de séquence

Une comparaison rend 0 ou 1, et bool ne stocke que ces deux valeurs. && et || court-circuitent : le second opérande peut ne pas être évalué. Deux modifications de la même variable entre deux points de séquence n'ont pas de valeur garantie.

03
méthode

Comment procéder

  1. Écrire les types et les tailles des cinq variables avant tout calcul.
  2. Promouvoir char et short en int, puis chercher le type le plus large présent dans l'expression.
  3. Parenthéser l'expression selon la table de priorité, du plus fort au plus faible.
  4. Écrire 0 ou 1 pour un booléen, et garder les chiffres utiles pour un double.
  5. Contrôler au débogueur, une instruction à la fois, en notant les quatre variables.

    return 0;
}

05
erreurs fréquentes

Les pièges

À vérifier
  • Croire que i/4 + d divise en réel : 9/4 vaut 2, le double n'intervient qu'après.
  • Oublier les parenthèses dans 7 >= 3 | 7 == 3 : gcc signale -Wparentheses, même si la valeur reste 1.
  • Attendre 12 de k = k++ + ++j : gcc 13.2 l'affiche, mais la norme ne garantit rien.
  • Afficher un double avec %d : le format ne correspond pas au type ; utiliser %f ou %.3f.
